# Skills App — Plan 1: Fundament

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eine lauffähige, täglich nutzbare Lern-App-Shell mit Skill-Runtime, SQLite-Backend, FSRS-Scheduler, Review-Flow, Lektions-Renderer und Statistik — bewiesen durch einen Demo-Skill.

**Architecture:** npm-Workspaces-Monorepo mit drei Paketen. `packages/core` enthält framework-freie Logik (Scheduler, Zod-Schemas, Parser) und wird von beiden Seiten importiert. `packages/server` ist ein Hono-Server mit better-sqlite3 und Drizzle, der allen veränderlichen Zustand hält. `packages/web` ist eine React-PWA, die Skill-Manifeste zur Buildzeit per `import.meta.glob` einsammelt und daraus Navigation und Routen erzeugt. Skills liegen außerhalb der Pakete unter `skills/` und werden nie vom Kern importiert — nur eingesammelt.

**Tech Stack:** Node 20+, TypeScript 5.6, Vitest 2, Hono 4 (`@hono/node-server`), better-sqlite3 11, drizzle-orm 0.36 + drizzle-kit, Zod 3, React 18, react-router-dom 6, @tanstack/react-query 5, Tailwind CSS 3, lucide-react, @mdx-js/rollup 3, vite-plugin-pwa 0.20, Playwright 1.48.

## Global Constraints

- Node-Version: 20 oder höher. `"type": "module"` in allen `package.json`.
- TypeScript strict: `"strict": true`, `"noUncheckedIndexedAccess": true`.
- Alle Oberflächentexte auf Deutsch. Code, Bezeichner und Commit-Messages auf Englisch.
- `packages/core` darf nichts aus `react`, `hono` oder `better-sqlite3` importieren. Rein funktional, keine I/O.
- Skill-Ordner unter `skills/` dürfen niemals aus `packages/server` importiert werden.
- Datenbankdatei liegt fest unter `data/app.db`, relativ zur Repo-Wurzel, überschreibbar per `SKILLS_DB_PATH`.
- Server-Port 5174, Web-Dev-Port 5173. Vite proxyt `/api` auf den Server.
- Jeder Task endet mit grünem `npm test` und einem Commit.
- Kartenidentität ist immer `skillId + moduleId + cardKey`. Nie ein Array-Index.

```ts
import { z } from "zod";

const slug = z
  .string()
  .min(1)
  .regex(/^[a-z0-9][a-z0-9-]*$/, "muss ein Slug aus Kleinbuchstaben, Ziffern und Bindestrichen sein");

export const moduleTypeSchema = z.enum([
  "course",
  "srs-deck",
  "reference",
  "practice",
  "library",
]);

export const skillModuleSchema = z.object({
  id: slug,
  type: moduleTypeSchema,
  title: z.string().min(1),
  subtitle: z.string().optional(),
  pinned: z.boolean().default(false),
  widget: z.string().min(1).optional(),
  data: z.array(z.string().min(1)).default([]),
  dailyNewLimit: z.number().int().positive().optional(),
  dailyReviewLimit: z.number().int().positive().optional(),
});

export const skillManifestSchema = z
  .object({
    id: slug,
    name: z.string().min(1),
    icon: z.string().min(1),
    accent: z.string().regex(/^#[0-9a-fA-F]{6}$/, "muss eine Hex-Farbe sein"),
    description: z.string().default(""),
    modules: z.array(skillModuleSchema).min(1),
  })
  .superRefine((manifest, ctx) => {
    const seen = new Set<string>();
    for (const mod of manifest.modules) {
      if (seen.has(mod.id)) {
        ctx.addIssue({
          code: z.ZodIssueCode.custom,
          path: ["modules"],
          message: `Modul-IDs müssen eindeutig sein: "${mod.id}" kommt mehrfach vor.`,
        });
      }
      seen.add(mod.id);
    }
  });

export type SkillModule = z.infer<typeof skillModuleSchema>;
export type SkillManifest = z.infer<typeof skillManifestSchema>;
export type ModuleType = z.infer<typeof moduleTypeSchema>;

export type ParseManifestResult =
  | { ok: true; manifest: SkillManifest }
  | { ok: false; error: string };

export function parseManifest(input: unknown): ParseManifestResult {
  const parsed = skillManifestSchema.safeParse(input);
  if (parsed.success) return { ok: true, manifest: parsed.data };
  const error = parsed.error.issues
    .map((issue) => `${issue.path.join(".") || "(wurzel)"}: ${issue.message}`)
    .join("; ");
  return { ok: false, error };
}
```

import { z } from "zod";

export const cardSchema = z.object({
  key: z.string().min(1),
  front: z.string().min(1),
  back: z.string().min(1),
  reading: z.string().optional(),
  note: z.string().optional(),
  example: z.string().optional(),
  tags: z.array(z.string()).default([]),
});

export const deckFileSchema = z.object({
  deck: z.string().min(1),
  cards: z.array(cardSchema).min(1),
});

export type Card = z.infer<typeof cardSchema>;
export type DeckFile = z.infer<typeof deckFileSchema>;

export type ParseDeckResult =
  | { ok: true; deck: DeckFile }
  | { ok: false; error: string };

export function parseDeckFile(input: unknown, source: string): ParseDeckResult {
  const parsed = deckFileSchema.safeParse(input);
  if (!parsed.success) {
    const detail = parsed.error.issues
      .map((issue) => `${issue.path.join(".") || "(wurzel)"}: ${issue.message}`)
      .join("; ");
    return { ok: false, error: `${source} — ${detail}` };
  }
  const seen = new Set<string>();
  for (const card of parsed.data.cards) {
    if (seen.has(card.key)) {
      return { ok: false, error: `${source} — Kartenschlüssel "${card.key}" kommt mehrfach vor.` };
    }
    seen.add(card.key);
  }
  return { ok: true, deck: parsed.data };
}

`packages/core/src/srs/fsrs.ts`:

```ts
import type { CardState, FsrsParams, Rating, SchedulingState } from "./types.js";

const MINUTE = 60_000;
const DAY = 86_400_000;

/**
 * Weights follow the FSRS-5 default set. Indices 0-3 seed initial stability
 * per rating; the rest drive stability and difficulty updates.
 */
export const DEFAULT_PARAMS: FsrsParams = {
  requestRetention: 0.9,
  maximumInterval: 36_500,
  weights: [
    0.4072, 1.1829, 3.1262, 15.4722, 7.2102, 0.5316, 1.0651, 0.0234, 1.616,
    0.1544, 1.0824, 1.9813, 0.0953, 0.2975, 2.2042, 0.2407, 2.9466, 0.5034,
    0.6567,
  ],
  learningStepsMinutes: [1, 10],
  relearningStepsMinutes: [10],
};

const DECAY = -0.5;
const FACTOR = 19 / 81;

function clampDifficulty(value: number): number {
  return Math.min(10, Math.max(1, value));
}

function initialDifficulty(w: readonly number[], rating: Rating): number {
  return clampDifficulty(w[4]! - Math.exp(w[5]! * (rating - 1)) + 1);
}

function initialStability(w: readonly number[], rating: Rating): number {
  return Math.max(0.1, w[rating - 1]!);
}

function nextDifficulty(w: readonly number[], difficulty: number, rating: Rating): number {
  const delta = difficulty - w[6]! * (rating - 3);
  const target = w[7]! * initialDifficulty(w, 4) + (1 - w[7]!) * delta;
  return clampDifficulty(target);
}

function retrievability(elapsedDays: number, stability: number): number {
  if (stability <= 0) return 0;
  return Math.pow(1 + (FACTOR * elapsedDays) / stability, DECAY);
}

function stabilityAfterRecall(
  w: readonly number[],
  difficulty: number,
  stability: number,
  retr: number,
  rating: Rating,
): number {
  const hardPenalty = rating === 2 ? w[15]! : 1;
  const easyBonus = rating === 4 ? w[16]! : 1;
  const growth =
    Math.exp(w[8]!) *
    (11 - difficulty) *
    Math.pow(stability, -w[9]!) *
    (Math.exp((1 - retr) * w[10]!) - 1) *
    hardPenalty *
    easyBonus;
  return Math.max(0.1, stability * (1 + growth));
}

function stabilityAfterLapse(
  w: readonly number[],
  difficulty: number,
  stability: number,
  retr: number,
): number {
  const next =
    w[11]! *
    Math.pow(difficulty, -w[12]!) *
    (Math.pow(stability + 1, w[13]!) - 1) *
    Math.exp((1 - retr) * w[14]!);
  return Math.max(0.1, Math.min(next, stability));
}

function intervalDays(stability: number, params: FsrsParams): number {
  const raw =
    (stability / FACTOR) * (Math.pow(params.requestRetention, 1 / DECAY) - 1);
  return Math.min(params.maximumInterval, Math.max(1, Math.round(raw)));
}

export function newSchedulingState(now: number): SchedulingState {
  return {
    state: "new",
    due: now,
    stability: 0,
    difficulty: 0,
    reps: 0,
    lapses: 0,
    lastReview: null,
  };
}

export function schedule(
  state: SchedulingState,
  rating: Rating,
  now: number,
  params: FsrsParams = DEFAULT_PARAMS,
): SchedulingState {
  const w = params.weights;
  const reps = state.reps + 1;

  if (state.state === "new") {
    const stability = initialStability(w, rating);
    const difficulty = initialDifficulty(w, rating);
    const graduating = rating >= 3;
    const nextState: CardState = graduating && rating === 4 ? "review" : "learning";
    const due =
      nextState === "review"
        ? now + intervalDays(stability, params) * DAY
        : now + params.learningStepsMinutes[rating >= 3 ? 1 : 0]! * MINUTE;
    return { state: nextState, due, stability, difficulty, reps, lapses: 0, lastReview: now };
  }

  const elapsedDays = state.lastReview === null ? 0 : Math.max(0, (now - state.lastReview) / DAY);
  const retr = retrievability(elapsedDays, state.stability);
  const difficulty = nextDifficulty(w, state.difficulty, rating);

  if (rating === 1) {
    const stability = stabilityAfterLapse(w, difficulty, state.stability, retr);
    const lapses = state.state === "review" ? state.lapses + 1 : state.lapses;
    return {
      state: "relearning",
      due: now + params.relearningStepsMinutes[0]! * MINUTE,
      stability,
      difficulty,
      reps,
      lapses,
      lastReview: now,
    };
  }

  const stability = stabilityAfterRecall(w, difficulty, state.stability, retr, rating);

  if (state.state === "learning" || state.state === "relearning") {
    if (rating === 2) {
      const steps =
        state.state === "learning" ? params.learningStepsMinutes : params.relearningStepsMinutes;
      return {
        state: state.state,
        due: now + steps[0]! * MINUTE,
        stability,
        difficulty,
        reps,
        lapses: state.lapses,
        lastReview: now,
      };
    }
    return {
      state: "review",
      due: now + intervalDays(stability, params) * DAY,
      stability,
      difficulty,
      reps,
      lapses: state.lapses,
      lastReview: now,
    };
  }

  return {
    state: "review",
    due: now + intervalDays(stability, params) * DAY,
    stability,
    difficulty,
    reps,
    lapses: state.lapses,
    lastReview: now,
  };
}

export function previewAll(
  state: SchedulingState,
  now: number,
  params: FsrsParams = DEFAULT_PARAMS,
): Record<Rating, SchedulingState> {
  return {
    1: schedule(state, 1, now, params),
    2: schedule(state, 2, now, params),
    3: schedule(state, 3, now, params),
    4: schedule(state, 4, now, params),
  };
}

import type { SchedulingState } from "./types.js";

export interface QueueCard {
  cardId: number;
  moduleId: string;
  scheduling: SchedulingState;
}

export interface QueueLimits {
  newPerDay: number;
  reviewsPerDay: number;
  newDoneToday: number;
  reviewsDoneToday: number;
}

const byDue = (a: QueueCard, b: QueueCard) => a.scheduling.due - b.scheduling.due;

export function buildQueue(cards: QueueCard[], limits: QueueLimits, now: number): QueueCard[] {
  const due = cards.filter((c) => c.scheduling.due <= now);

  const steps = due
    .filter((c) => c.scheduling.state === "learning" || c.scheduling.state === "relearning")
    .sort(byDue);

  const reviewBudget = Math.max(0, limits.reviewsPerDay - limits.reviewsDoneToday);
  const reviews = due
    .filter((c) => c.scheduling.state === "review")
    .sort(byDue)
    .slice(0, reviewBudget);

  const newBudget = Math.max(0, limits.newPerDay - limits.newDoneToday);
  const fresh = due
    .filter((c) => c.scheduling.state === "new")
    .sort((a, b) => a.cardId - b.cardId)
    .slice(0, newBudget);

  return [...steps, ...reviews, ...fresh];
}

import { newSchedulingState } from "@skills/core";
import type { AppDatabase } from "../db/client.js";

export interface SeedCard {
  moduleId: string;
  cardKey: string;
  front: string;
  back: string;
  reading?: string;
  note?: string;
  example?: string;
  tags: string[];
}

export interface SeedRequest {
  skillId: string;
  name: string;
  modules: { id: string; type: string; title: string }[];
  cards: SeedCard[];
}

export interface SeedResult {
  created: number;
  updated: number;
  archived: number;
  unchanged: number;
}

interface ExistingRow {
  id: number;
  module_id: string;
  card_key: string;
  front_json: string;
  back_json: string;
  tags: string;
  state: string;
}

function frontOf(card: SeedCard): string {
  return JSON.stringify({ text: card.front });
}

function backOf(card: SeedCard): string {
  return JSON.stringify({
    text: card.back,
    reading: card.reading ?? null,
    note: card.note ?? null,
    example: card.example ?? null,
  });
}

export function syncSkill(database: AppDatabase, request: SeedRequest, now: number): SeedResult {
  const { raw } = database;
  const result: SeedResult = { created: 0, updated: 0, archived: 0, unchanged: 0 };

  const run = raw.transaction(() => {
    raw
      .prepare("INSERT INTO skills (id, installed_at) VALUES (?, ?) ON CONFLICT(id) DO NOTHING")
      .run(request.skillId, now);

    const upsertModule = raw.prepare(
      `INSERT INTO modules (id, skill_id, type, title) VALUES (?, ?, ?, ?)
       ON CONFLICT(skill_id, id) DO UPDATE SET type = excluded.type, title = excluded.title`,
    );
    for (const mod of request.modules) {
      upsertModule.run(mod.id, request.skillId, mod.type, mod.title);
    }

    const existing = raw
      .prepare(
        "SELECT id, module_id, card_key, front_json, back_json, tags, state FROM cards WHERE skill_id = ?",
      )
      .all(request.skillId) as ExistingRow[];
    const byIdentity = new Map(existing.map((row) => [`${row.module_id} ${row.card_key}`, row]));

    const insertCard = raw.prepare(
      `INSERT INTO cards (skill_id, module_id, card_key, front_json, back_json, tags, state)
       VALUES (?, ?, ?, ?, ?, ?, 'active')`,
    );
    const insertScheduling = raw.prepare(
      `INSERT INTO scheduling (card_id, state, due, stability, difficulty, reps, lapses, last_review)
       VALUES (?, ?, ?, ?, ?, ?, ?, ?)`,
    );
    const updateCard = raw.prepare(
      "UPDATE cards SET front_json = ?, back_json = ?, tags = ?, state = 'active' WHERE id = ?",
    );
    const archiveCard = raw.prepare("UPDATE cards SET state = 'archived' WHERE id = ?");

    const seen = new Set<string>();
    for (const card of request.cards) {
      const identity = `${card.moduleId} ${card.cardKey}`;
      seen.add(identity);
      const front = frontOf(card);
      const back = backOf(card);
      const tags = JSON.stringify(card.tags);
      const row = byIdentity.get(identity);

      if (!row) {
        const info = insertCard.run(request.skillId, card.moduleId, card.cardKey, front, back, tags);
        const fresh = newSchedulingState(now);
        insertScheduling.run(
          Number(info.lastInsertRowid),
          fresh.state,
          fresh.due,
          fresh.stability,
          fresh.difficulty,
          fresh.reps,
          fresh.lapses,
          fresh.lastReview,
        );
        result.created += 1;
        continue;
      }

      const identical =
        row.front_json === front &&
        row.back_json === back &&
        row.tags === tags &&
        row.state === "active";
      if (identical) {
        result.unchanged += 1;
      } else {
        updateCard.run(front, back, tags, row.id);
        result.updated += 1;
      }
    }

    for (const row of existing) {
      const identity = `${row.module_id} ${row.card_key}`;
      if (!seen.has(identity) && row.state !== "archived") {
        archiveCard.run(row.id);
        result.archived += 1;
      }
    }
  });

  run();
  return result;
}

import { z } from "zod";
import type { AppEnv } from "../app.js";
import type { AppDatabase } from "../db/client.js";

const reviewSchema = z.object({
  cardId: z.number().int().positive(),
  rating: z.union([z.literal(1), z.literal(2), z.literal(3), z.literal(4)]),
  elapsedMs: z.number().int().nonnegative().default(0),
});

interface CardRow {
  id: number;
  skill_id: string;
  module_id: string;
  card_key: string;
  front_json: string;
  back_json: string;
  tags: string;
  state: string;
  due: number;
  stability: number;
  difficulty: number;
  reps: number;
  lapses: number;
  last_review: number | null;
}

function readSetting(database: AppDatabase, key: string, fallback: number): number {
  const row = database.raw.prepare("SELECT value FROM settings WHERE key = ?").get(key) as
    | { value: string }
    | undefined;
  if (!row) return fallback;
  const parsed = Number(row.value);
  return Number.isFinite(parsed) ? parsed : fallback;
}

function startOfLocalDay(now: number): number {
  const d = new Date(now);
  d.setHours(0, 0, 0, 0);
  return d.getTime();
}

function toSchedulingState(row: CardRow): SchedulingState {
  return {
    state: row.state as SchedulingState["state"],
    due: row.due,
    stability: row.stability,
    difficulty: row.difficulty,
    reps: row.reps,
    lapses: row.lapses,
    lastReview: row.last_review,
  };
}

export const reviewRoutes = new Hono<AppEnv>();

reviewRoutes.get("/api/queue", (c) => {
  const database = c.get("database");
  const now = Date.now();
  const skillId = c.req.query("skillId");
  const moduleId = c.req.query("moduleId");
  const limit = Number(c.req.query("limit") ?? "0");

  const conditions = ["c.state = 'active'", "s.suspended = 0", "(s.buried_until IS NULL OR s.buried_until <= ?)"];
  const params: unknown[] = [now];
  if (skillId) {
    conditions.push("c.skill_id = ?");
    params.push(skillId);
  }
  if (moduleId) {
    conditions.push("c.module_id = ?");
    params.push(moduleId);
  }

  const rows = database.raw
    .prepare(
      `SELECT c.id, c.skill_id, c.module_id, c.card_key, c.front_json, c.back_json, c.tags,
              s.state, s.due, s.stability, s.difficulty, s.reps, s.lapses, s.last_review
       FROM cards c JOIN scheduling s ON s.card_id = c.id
       WHERE ${conditions.join(" AND ")}`,
    )
    .all(...params) as CardRow[];

  const dayStart = startOfLocalDay(now);
  const doneToday = database.raw
    .prepare(
      `SELECT
         SUM(CASE WHEN state_before = 'new' THEN 1 ELSE 0 END) AS newDone,
         SUM(CASE WHEN state_before = 'review' THEN 1 ELSE 0 END) AS reviewDone
       FROM reviews WHERE reviewed_at >= ?`,
    )
    .get(dayStart) as { newDone: number | null; reviewDone: number | null };

  const queueInput: QueueCard[] = rows.map((row) => ({
    cardId: row.id,
    moduleId: row.module_id,
    scheduling: toSchedulingState(row),
  }));

  const queued = buildQueue(
    queueInput,
    {
      newPerDay: readSetting(database, "dailyNew", 20),
      reviewsPerDay: readSetting(database, "dailyReviews", 200),
      newDoneToday: doneToday.newDone ?? 0,
      reviewsDoneToday: doneToday.reviewDone ?? 0,
    },
    now,
  );

  const byId = new Map(rows.map((row) => [row.id, row]));
  const limited = limit > 0 ? queued.slice(0, limit) : queued;

  const cards = limited.map((entry) => {
    const row = byId.get(entry.cardId)!;
    const preview = previewAll(entry.scheduling, now);
    return {
      id: row.id,
      skillId: row.skill_id,
      moduleId: row.module_id,
      cardKey: row.card_key,
      front: JSON.parse(row.front_json),
      back: JSON.parse(row.back_json),
      tags: JSON.parse(row.tags),
      scheduling: entry.scheduling,
      preview: {
        1: { due: preview[1].due },
        2: { due: preview[2].due },
        3: { due: preview[3].due },
        4: { due: preview[4].due },
      },
    };
  });

  return c.json({ cards });

reviewRoutes.post("/api/reviews", async (c) => {
  const database = c.get("database");
  const body = await c.req.json().catch(() => null);
  const parsed = reviewSchema.safeParse(body);
  if (!parsed.success) {
    return c.json(
      { error: { code: "invalid_body", message: parsed.error.issues.map((i) => i.message).join("; ") } },
      400,
    );
  }

  const row = database.raw
    .prepare(
      `SELECT c.id, c.skill_id, c.module_id, c.card_key, c.front_json, c.back_json, c.tags,
              s.state, s.due, s.stability, s.difficulty, s.reps, s.lapses, s.last_review
       FROM cards c JOIN scheduling s ON s.card_id = c.id WHERE c.id = ?`,
    )
    .get(parsed.data.cardId) as CardRow | undefined;

  if (!row) {
    return c.json({ error: { code: "not_found", message: "Karte nicht gefunden." } }, 404);
  }

  const now = Date.now();
  const before = toSchedulingState(row);
  const after = schedule(before, parsed.data.rating as Rating, now);

  const write = database.raw.transaction(() => {
    database.raw
      .prepare(
        `UPDATE scheduling SET state = ?, due = ?, stability = ?, difficulty = ?,
                reps = ?, lapses = ?, last_review = ?, buried_until = NULL WHERE card_id = ?`,
      )
      .run(after.state, after.due, after.stability, after.difficulty, after.reps, after.lapses, after.lastReview, row.id);
    database.raw
      .prepare(
        `INSERT INTO reviews (card_id, reviewed_at, rating, elapsed_ms, state_before, state_after)
         VALUES (?, ?, ?, ?, ?, ?)`,
      )
      .run(row.id, now, parsed.data.rating, parsed.data.elapsedMs, before.state, after.state);
  });
  write();

  return c.json({ scheduling: after });
});

reviewRoutes.post("/api/cards/:id/suspend", async (c) => {
  const database = c.get("database");

  - `GET /api/stats` → `{ heatmap: { day: string; count: number }[]; retention: number; states: Record<CardState, number>; forecast: { day: string; count: number }[]; streak: number }`

`heatmap` deckt die letzten 365 Tage ab, `forecast` die nächsten 30. `retention` ist der Anteil der Bewertungen ≥ 2 unter allen Bewertungen von Karten, die vorher im Zustand `review` waren; ohne solche Bewertungen ist sie `0`. `streak` zählt aufeinanderfolgende Tage mit mindestens einer Bewertung, rückwärts ab heute; ein reviewfreier heutiger Tag bricht die Serie nicht, solange gestern gelernt wurde.

`packages/server/src/routes/stats.ts`:

```ts
import { Hono } from "hono";
import type { AppEnv } from "../app.js";

const DAY = 86_400_000;

function dayKey(ts: number): string {
  const d = new Date(ts);
  const month = String(d.getMonth() + 1).padStart(2, "0");
  const day = String(d.getDate()).padStart(2, "0");
  return `${d.getFullYear()}-${month}-${day}`;
}

function startOfLocalDay(ts: number): number {
  const d = new Date(ts);
  d.setHours(0, 0, 0, 0);
  return d.getTime();
}

export const statsRoutes = new Hono<AppEnv>();

statsRoutes.get("/api/stats", (c) => {
  const { raw } = c.get("database");
  const now = Date.now();
  const today = startOfLocalDay(now);

  const reviewRows = raw
    .prepare("SELECT reviewed_at AS reviewedAt, rating, state_before AS stateBefore FROM reviews WHERE reviewed_at >= ?")
    .all(today - 364 * DAY) as { reviewedAt: number; rating: number; stateBefore: string }[];

  const counts = new Map<string, number>();
  for (const row of reviewRows) {
    const key = dayKey(row.reviewedAt);
    counts.set(key, (counts.get(key) ?? 0) + 1);
  }
  const heatmap = Array.from({ length: 365 }, (_, i) => {
    const ts = today - (364 - i) * DAY;
    const key = dayKey(ts);
    return { day: key, count: counts.get(key) ?? 0 };
  });

  const reviewStateRows = reviewRows.filter((row) => row.stateBefore === "review");
  const retention =
    reviewStateRows.length === 0
      ? 0
      : reviewStateRows.filter((row) => row.rating >= 2).length / reviewStateRows.length;

  const stateRows = raw
    .prepare(
      `SELECT s.state AS state, COUNT(*) AS count
       FROM scheduling s JOIN cards c ON c.id = s.card_id
       WHERE c.state = 'active' GROUP BY s.state`,
    )
    .all() as { state: string; count: number }[];
  const states: Record<string, number> = { new: 0, learning: 0, review: 0, relearning: 0 };
  for (const row of stateRows) states[row.state] = row.count;

  const dueRows = raw
    .prepare(
      `SELECT s.due AS due FROM scheduling s JOIN cards c ON c.id = s.card_id
       WHERE c.state = 'active' AND s.suspended = 0 AND s.due < ?`,
    )
    .all(today + 30 * DAY) as { due: number }[];
  const dueCounts = new Map<string, number>();
  for (const row of dueRows) {
    const bucket = row.due < today ? dayKey(today) : dayKey(row.due);
    dueCounts.set(bucket, (dueCounts.get(bucket) ?? 0) + 1);
  }
  const forecast = Array.from({ length: 30 }, (_, i) => {
    const key = dayKey(today + i * DAY);
    return { day: key, count: dueCounts.get(key) ?? 0 };
  });

  let streak = 0;
  const activeDays = new Set(reviewRows.map((row) => dayKey(row.reviewedAt)));
  let cursor = activeDays.has(dayKey(today)) ? today : today - DAY;
  while (activeDays.has(dayKey(cursor))) {
    streak += 1;
    cursor -= DAY;
  }

  return c.json({ heatmap, retention, states, forecast, streak });
});
```

import { mkdirSync, readFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { Hono } from "hono";
import type { AppEnv } from "../app.js";

function stamp(now: number): string {
  const d = new Date(now);
  const month = String(d.getMonth() + 1).padStart(2, "0");
  const day = String(d.getDate()).padStart(2, "0");
  const hour = String(d.getHours()).padStart(2, "0");
  const minute = String(d.getMinutes()).padStart(2, "0");
  return `${d.getFullYear()}-${month}-${day}_${hour}${minute}`;
}

export const backupRoutes = new Hono<AppEnv>();

backupRoutes.get("/api/backup/export", async (c) => {
  const database = c.get("database");
  if (database.path === ":memory:") {
    return c.json(
      { error: { code: "no_file_database", message: "Es läuft eine Datenbank im Arbeitsspeicher." } },
      400,
    );
  }
  const tmpTarget = join(dirname(database.path), `.export-${Date.now()}.db`);
  await database.backupTo(tmpTarget);
  const bytes = readFileSync(tmpTarget);
  const filename = `skills-${stamp(Date.now()).slice(0, 10)}.db`;
  return c.body(bytes, 200, {
    "content-type": "application/octet-stream",
    "content-disposition": `attachment; filename="${filename}"`,
  });
});

backupRoutes.post("/api/backup/snapshot", async (c) => {
  const database = c.get("database");
  if (database.path === ":memory:") {
    return c.json(
      { error: { code: "no_file_database", message: "Es läuft eine Datenbank im Arbeitsspeicher." } },
      400,
    );
  }
  const dir = join(dirname(database.path), "backups");
  mkdirSync(dir, { recursive: true });
  const target = join(dir, `app-${stamp(Date.now())}.db`);
  await database.backupTo(target);
  return c.json({ path: target });
});

import { createContext, useCallback, useContext, useEffect, useMemo, useState, type ReactNode } from "react";

export type ThemePreference = "light" | "dark" | "system";
export type Theme = "light" | "dark";

interface ThemeContextValue {
  theme: Theme;
  preference: ThemePreference;
  setTheme: (preference: ThemePreference) => void;
}

const ThemeContext = createContext<ThemeContextValue | null>(null);
const STORAGE_KEY = "skills.theme";

function systemTheme(): Theme {
  return window.matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light";
}

export function ThemeProvider({ children }: { children: ReactNode }) {
  const [preference, setPreference] = useState<ThemePreference>(() => {
    const stored = localStorage.getItem(STORAGE_KEY);
    return stored === "light" || stored === "dark" ? stored : "system";
  });

  const theme: Theme = preference === "system" ? systemTheme() : preference;

  useEffect(() => {
    document.documentElement.classList.toggle("dark", theme === "dark");
  }, [theme]);

  const setTheme = useCallback((next: ThemePreference) => {
    setPreference(next);
    if (next === "system") localStorage.removeItem(STORAGE_KEY);
    else localStorage.setItem(STORAGE_KEY, next);
  }, []);

  const value = useMemo(() => ({ theme, preference, setTheme }), [theme, preference, setTheme]);
  return <ThemeContext.Provider value={value}>{children}</ThemeContext.Provider>;
}

export function useTheme(): ThemeContextValue {
  const value = useContext(ThemeContext);
  if (!value) throw new Error("useTheme muss innerhalb von ThemeProvider verwendet werden.");
  return value;
}

import { parseManifest, type SkillManifest } from "@skills/core";

export interface LoadedSkill {
  manifest: SkillManifest;
  dir: string;
  data: Record<string, unknown>;
}

export interface BrokenSkill {
  dir: string;
  error: string;
}

export interface LoadResult {
  skills: LoadedSkill[];
  broken: BrokenSkill[];
}

function dirOf(path: string): string {
  const match = /\/skills\/([^/]+)\//.exec(path);
  return match?.[1] ?? path;
}

function relativeOf(path: string, dir: string): string {
  const marker = `/skills/${dir}/`;
  return path.slice(path.indexOf(marker) + marker.length);
}

function unwrap(mod: unknown): unknown {
  if (mod && typeof mod === "object" && "default" in mod) {
    return (mod as { default: unknown }).default;
  }
  return mod;
}

function patternToRegExp(pattern: string): RegExp {
  const escaped = pattern.replace(/[.+^${}()|[\]\\]/g, "\\$&").replace(/\*/g, "[^/]*");
  return new RegExp(`^${escaped}$`);
}

export function loadSkills(
  manifestModules: Record<string, unknown>,
  dataModules: Record<string, unknown>,
): LoadResult {
  const skills: LoadedSkill[] = [];
  const broken: BrokenSkill[] = [];

  const dataByDir = new Map<string, Map<string, unknown>>();
  for (const [path, mod] of Object.entries(dataModules)) {
    const dir = dirOf(path);
    const bucket = dataByDir.get(dir) ?? new Map<string, unknown>();
    bucket.set(relativeOf(path, dir), unwrap(mod));
    dataByDir.set(dir, bucket);
  }

  for (const [path, mod] of Object.entries(manifestModules)) {
    const dir = dirOf(path);
    const parsed = parseManifest(unwrap(mod));
    if (!parsed.ok) {
      broken.push({ dir, error: parsed.error });
      continue;
    }

    const available = dataByDir.get(dir) ?? new Map<string, unknown>();
    const data: Record<string, unknown> = {};
    let missing: string | null = null;

    for (const module of parsed.manifest.modules) {
      for (const entry of module.data) {
        if (entry.includes("*")) {
          const re = patternToRegExp(entry);
          for (const [key, value] of available) {
            if (re.test(key)) data[key] = value;
          }
          continue;
        }
        const value = available.get(entry);
        if (value === undefined) {
          missing = entry;
          break;
        }
        data[entry] = value;
      }
      if (missing) break;
    }

    if (missing) {
      broken.push({ dir, error: `Datei aus dem Manifest fehlt: ${missing}` });
      continue;
    }

    skills.push({ manifest: parsed.manifest, dir, data });
  }

  skills.sort((a, b) => a.manifest.name.localeCompare(b.manifest.name, "de"));
  return { skills, broken };
}

const manifestGlob = import.meta.glob("../../../../skills/*/skill.json", { eager: true });
const dataGlob = import.meta.glob("../../../../skills/*/**/*.json", { eager: true });

let cached: LoadResult | null = null;

function result(): LoadResult {
  if (!cached) {
    const dataOnly = Object.fromEntries(
      Object.entries(dataGlob).filter(([path]) => !path.endsWith("/skill.json")),
    );
    cached = loadSkills(manifestGlob, dataOnly);
    for (const entry of cached.broken) {
      console.error(`Skill "${entry.dir}" wurde nicht geladen: ${entry.error}`);
    }
  }
  return cached;
}

export function getSkills(): LoadedSkill[] {
  return result().skills;
}

export function getBrokenSkills(): BrokenSkill[] {
  return result().broken;
}

export function getSkill(id: string): LoadedSkill | undefined {
  return getSkills().find((skill) => skill.manifest.id === id);
}

export function loadWidget(

  widgetName: string,
): LazyExoticComponent<ComponentType<WidgetProps>> | null {
  const suffix = `/skills/${skillId}/widgets/${widgetName}.tsx`;

export class ApiError extends Error {
  readonly code: string;
  constructor(code: string, message: string) {
    super(message);
    this.name = "ApiError";
    this.code = code;
  }
}

async function request<T>(path: string, init?: RequestInit): Promise<T> {
  let response: Response;
  try {
    response = await fetch(path, {
      ...init,
      headers: { "content-type": "application/json", ...(init?.headers ?? {}) },
    });
  } catch {
    throw new ApiError("offline", "Der Server ist nicht erreichbar. Läuft er noch?");
  }

  if (!response.ok) {
    const body = (await response.json().catch(() => null)) as
      | { error?: { code?: string; message?: string } }
      | null;
    throw new ApiError(
      body?.error?.code ?? "unknown",
      body?.error?.message ?? `Anfrage fehlgeschlagen (${response.status}).`,
    );
  }

import { parseDeckFile } from "@skills/core";
import { useEffect, useState } from "react";
import { api } from "../api/client.js";
import type { SeedCard, SeedRequest, SeedResult } from "../api/types.js";
import { getSkills, type LoadedSkill } from "./registry.js";

export function buildSeedPayload(skill: LoadedSkill): SeedRequest {
  const cards: SeedCard[] = [];

  for (const module of skill.manifest.modules) {
    if (module.type !== "srs-deck") continue;
    for (const [source, value] of Object.entries(skill.data)) {
      const declared = module.data.some((entry) =>
        entry.includes("*")
          ? new RegExp(`^${entry.replace(/\*/g, "[^/]*")}$`).test(source)
          : entry === source,
      );
      if (!declared) continue;

      const parsed = parseDeckFile(value, source);
      if (!parsed.ok) throw new Error(parsed.error);

      for (const card of parsed.deck.cards) {
        cards.push({
          moduleId: module.id,
          cardKey: card.key,
          front: card.front,
          back: card.back,
          ...(card.reading ? { reading: card.reading } : {}),
          ...(card.note ? { note: card.note } : {}),
          ...(card.example ? { example: card.example } : {}),
          tags: card.tags,
        });
      }
    }
  }

  return {
    skillId: skill.manifest.id,
    name: skill.manifest.name,
    modules: skill.manifest.modules.map((m) => ({ id: m.id, type: m.type, title: m.title })),
    cards,
  };
}

export type SeedStatus = "idle" | "syncing" | "done" | "error";

export function useSeedSync(): { status: SeedStatus; error: string | null } {
  const [status, setStatus] = useState<SeedStatus>("idle");
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    let cancelled = false;
    setStatus("syncing");

    (async () => {
      try {
        for (const skill of getSkills()) {
          await api.post<SeedResult>("/api/skills/sync", buildSeedPayload(skill));
        }
        if (!cancelled) setStatus("done");
      } catch (e) {
        if (cancelled) return;
        setError(e instanceof Error ? e.message : String(e));
        setStatus("error");
      }
    })();

    return () => {
      cancelled = true;
    };
  }, []);

  return { status, error };
}

import { api } from "../api/client.js";

export type PracticeResult = "correct" | "wrong";

export interface ProgressApi {
  record(itemId: string, result: PracticeResult): void;
  get(itemId: string): PracticeResult | null;
  complete(moduleId: string): Promise<void>;
}

function storageKey(skillId: string): string {
  return `skills.progress.${skillId}`;
}

function readAll(skillId: string): Record<string, PracticeResult> {
  const raw = localStorage.getItem(storageKey(skillId));
  if (!raw) return {};
  try {
    return JSON.parse(raw) as Record<string, PracticeResult>;
  } catch {
    return {};
  }
}

export function createProgressApi(skillId: string): ProgressApi {
  return {
    record(itemId, result) {
      const all = readAll(skillId);
      all[itemId] = result;
      localStorage.setItem(storageKey(skillId), JSON.stringify(all));
    },
    get(itemId) {
      return readAll(skillId)[itemId] ?? null;
    },
    async complete(moduleId) {
      await api.put(`/api/progress/${skillId}/${moduleId}`, { status: "done", checkpoint: {} });
    },
  };
}

const MINUTE = 60_000;
const HOUR = 60 * MINUTE;
const DAY = 24 * HOUR;
const MONTH = 30 * DAY;

export function formatDue(due: number, now: number): string {
  const delta = due - now;
  if (delta < MINUTE) return "jetzt";
  if (delta < HOUR) return `in ${Math.round(delta / MINUTE)} Min.`;
  if (delta < DAY) return `in ${Math.round(delta / HOUR)} Std.`;
  if (delta < MONTH) {
    const days = Math.round(delta / DAY);
    return days === 1 ? "in 1 Tag" : `in ${days} Tagen`;
  }
  const months = Math.round(delta / MONTH);
  return months === 1 ? "in 1 Monat" : `in ${months} Monaten`;
}

import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";

import { api, ApiError } from "../../api/client.js";
import type { ReviewCard } from "../../api/types.js";

const RATINGS = [
  { rating: 1 as const, label: "Nochmal", key: "1" },
  { rating: 2 as const, label: "Schwer", key: "2" },
  { rating: 3 as const, label: "Gut", key: "3" },
  { rating: 4 as const, label: "Leicht", key: "4" },
];

export function ReviewSession() {
  const [params] = useSearchParams();
  const skillId = params.get("skillId");
  const moduleId = params.get("moduleId");
  const queryKey = ["queue", skillId, moduleId];
  const queryClient = useQueryClient();

  const [revealed, setRevealed] = useState(false);
  const [index, setIndex] = useState(0);
  const [shownAt, setShownAt] = useState(() => Date.now());

  const search = new URLSearchParams();
  if (skillId) search.set("skillId", skillId);
  if (moduleId) search.set("moduleId", moduleId);

  const query = useQuery({
    queryKey,
    queryFn: () => api.get<{ cards: ReviewCard[] }>(`/api/queue?${search.toString()}`),
  });

  const rate = useMutation({
    mutationFn: (input: { cardId: number; rating: 1 | 2 | 3 | 4; elapsedMs: number }) =>
      api.post("/api/reviews", input),
    onSuccess: () => {
      setRevealed(false);
      setShownAt(Date.now());
      setIndex((i) => i + 1);
      void queryClient.invalidateQueries({ queryKey: ["stats"] });
    },
  });

  const cards = query.data?.cards ?? [];
  const card = cards[index];

  const submit = useCallback(
    (rating: 1 | 2 | 3 | 4) => {
      if (!card) return;
      rate.mutate({ cardId: card.id, rating, elapsedMs: Date.now() - shownAt });
    },
    [card, rate, shownAt],
  );

  useEffect(() => {
    const onKey = (event: KeyboardEvent) => {
      if (event.key === " ") {
        event.preventDefault();
        setRevealed(true);
        return;
      }
      if (!revealed) return;
      const match = RATINGS.find((r) => r.key === event.key);
      if (match) submit(match.rating);
    };
    window.addEventListener("keydown", onKey);
    return () => window.removeEventListener("keydown", onKey);
  }, [revealed, submit]);

  if (query.isPending) return <p>Wird geladen…</p>;

  if (query.isError) {
    const message = query.error instanceof ApiError ? query.error.message : "Unbekannter Fehler.";
    return (

        <p className="text-red-600 dark:text-red-400">{message}</p>
        <button
          type="button"
          className="rounded border border-slate-300 px-3 py-1 dark:border-slate-700"
          onClick={() => void query.refetch()}
        >
          Erneut versuchen
        </button>
      </div>
    );
  }

  if (!card) {
    return <p className="text-slate-600 dark:text-slate-400">Nichts mehr fällig. Bis später.</p>;
  }

  return (
    <div className="mx-auto max-w-2xl space-y-6">
      <p className="text-sm text-slate-500">
        Karte {index + 1} von {cards.length}
      </p>

      <div className="rounded-lg border border-slate-200 p-8 text-center dark:border-slate-800">
        <div className="text-3xl">{card.front.text}</div>
        {revealed ? (
          <div className="mt-6 border-t border-slate-200 pt-6 dark:border-slate-800">
            {card.back.reading ? <div className="text-lg text-slate-500">{card.back.reading}</div> : null}
            <div className="text-2xl">{card.back.text}</div>

          </div>
        ) : null}
      </div>

      {revealed ? (
        <div className="grid grid-cols-4 gap-2">
          {RATINGS.map((entry) => (
            <button
              key={entry.rating}
              type="button"
              disabled={rate.isPending}
              onClick={() => submit(entry.rating)}
              className="rounded border border-slate-300 px-2 py-3 text-sm hover:bg-slate-100 disabled:opacity-50 dark:border-slate-700 dark:hover:bg-slate-900"

              <div className="font-medium">{entry.label}</div>
              <div className="text-xs text-slate-500">
                {formatDue(card.preview[String(entry.rating) as "1" | "2" | "3" | "4"].due, Date.now())}
              </div>
            </button>
          ))}
        </div>
      ) : (
        <button
          type="button"
          onClick={() => setRevealed(true)}
          className="w-full rounded bg-slate-900 px-4 py-3 text-white dark:bg-slate-100 dark:text-slate-900"
        >
          Aufdecken (Leertaste)
        </button>
      )}
    </div>
  );
}

export interface LessonMeta {
  id: string;
  title: string;
  order: number;
  requires: string | null;
}

export function sortLessons(lessons: LessonMeta[]): LessonMeta[] {
  return [...lessons].sort((a, b) => a.order - b.order || a.id.localeCompare(b.id, "de"));
}

export function isUnlocked(lesson: LessonMeta, done: Set<string>): boolean {
  return lesson.requires === null || done.has(lesson.requires);
}

import { MDXProvider } from "@mdx-js/react";
import { useQuery, useQueryClient } from "@tanstack/react-query";
import { Suspense, lazy, useMemo, useState, type ComponentType } from "react";
import { api } from "../api/client.js";
import { mdxComponents } from "../mdx/components.js";
import { isUnlocked, sortLessons, type LessonMeta } from "../mdx/lessons.js";

const lessonModules = import.meta.glob("../../../../skills/*/lessons/*.mdx");
const lessonMeta = import.meta.glob("../../../../skills/*/lessons/*.mdx", {
  eager: true,
  import: "meta",
});

interface ProgressResponse {
  lessons: { lessonId: string; status: string }[];
}

export function CourseRenderer({ skillId, title }: { skillId: string; title: string }) {
  const queryClient = useQueryClient();
  const [openId, setOpenId] = useState<string | null>(null);

  const progress = useQuery({
    queryKey: ["progress", skillId],
    queryFn: () => api.get<ProgressResponse>(`/api/progress/${skillId}`),
  });

  const lessons = useMemo(() => {
    const prefix = `/skills/${skillId}/lessons/`;
    const entries: { meta: LessonMeta; path: string }[] = [];
    for (const [path, meta] of Object.entries(lessonMeta)) {
      if (!path.includes(prefix)) continue;
      entries.push({ meta: meta as LessonMeta, path });
    }
    return sortLessons(entries.map((e) => e.meta)).map((meta) => ({
      meta,
      path: entries.find((e) => e.meta.id === meta.id)!.path,
    }));
  }, [skillId]);

  const done = new Set(
    (progress.data?.lessons ?? []).filter((l) => l.status === "done").map((l) => l.lessonId),
  );

  const openEntry = lessons.find((l) => l.meta.id === openId);
  const Lesson = openEntry
    ? (lazy(lessonModules[openEntry.path] as () => Promise<{ default: ComponentType }>) as ComponentType)
    : null;

  async function markDone(lessonId: string) {
    await api.put(`/api/progress/${skillId}/${lessonId}`, { status: "done", checkpoint: {} });
    await queryClient.invalidateQueries({ queryKey: ["progress", skillId] });
  }

  if (Lesson && openEntry) {
    return (
      <div className="mx-auto max-w-3xl">
        <button type="button" onClick={() => setOpenId(null)} className="mb-4 text-sm text-slate-500">
          ← Zurück zur Übersicht

        <MDXProvider components={{ ...mdxComponents, Checkpoint: (props: { children: React.ReactNode }) => (
          <mdxComponents.Checkpoint onDone={() => void markDone(openEntry.meta.id)}>
            {props.children}
          </mdxComponents.Checkpoint>
        ) }}>
          <Suspense fallback={<p>Lektion wird geladen…</p>}>
            <article className="prose prose-slate mt-4 dark:prose-invert">
              <Lesson />
            </article>
          </Suspense>
        </MDXProvider>
      </div>
    );
  }

  return (
    <div className="space-y-4">
      <h1 className="text-2xl font-semibold">{title}</h1>
      <ol className="space-y-2">
        {lessons.map(({ meta }) => {
          const unlocked = isUnlocked(meta, done);
          return (
            <li key={meta.id}>
              <button
                type="button"
                disabled={!unlocked}

                </span>
              </button>
            </li>
          );
        })}
      </ol>
    </div>
  );
}

import { Suspense, useMemo } from "react";
import { useParams } from "react-router-dom";
import { CourseRenderer } from "../renderers/CourseRenderer.js";
import { DeckRenderer } from "../renderers/DeckRenderer.js";
import { LibraryRenderer } from "../renderers/LibraryRenderer.js";
import { ReferenceRenderer } from "../renderers/ReferenceRenderer.js";
import { createProgressApi } from "./ProgressApi.js";
import { getSkill } from "./registry.js";
import { loadWidget } from "./widgets.js";

function collect(data: Record<string, unknown>, patterns: string[]): unknown[] {
  const result: unknown[] = [];
  for (const [key, value] of Object.entries(data)) {
    const matches = patterns.some((pattern) =>
      pattern.includes("*")
        ? new RegExp(`^${pattern.replace(/\*/g, "[^/]*")}$`).test(key)
        : pattern === key,
    );
    if (!matches) continue;
    if (Array.isArray(value)) result.push(...value);
    else result.push(value);
  }
  return result;
}

export function ModuleRoute() {
  const { skillId, moduleId } = useParams();
  const skill = skillId ? getSkill(skillId) : undefined;
  const module = skill?.manifest.modules.find((m) => m.id === moduleId);

  const progress = useMemo(() => createProgressApi(skillId ?? ""), [skillId]);
  const Widget = useMemo(
    () => (skill && module?.widget ? loadWidget(skill.manifest.id, module.widget) : null),
    [skill, module],
  );

  if (!skill || !module) {
    return <p className="text-slate-600 dark:text-slate-400">Dieses Modul existiert nicht.</p>;
  }

  const data = collect(skill.data, module.data);

  if (Widget) {
    return (
      <Suspense fallback={<p>Wird geladen…</p>}>
        <Widget data={data} progress={progress} settings={{}} />
      </Suspense>
    );
  }

  switch (module.type) {
    case "srs-deck":
      return <DeckRenderer skillId={skill.manifest.id} moduleId={module.id} title={module.title} />;
    case "course":
      return <CourseRenderer skillId={skill.manifest.id} title={module.title} />;
    case "reference":
      return <ReferenceRenderer title={module.title} data={data} />;
    case "library":
      return <LibraryRenderer title={module.title} data={data} />;
    case "practice":
      return (
        <div>
          <h1 className="text-2xl font-semibold">{module.title}</h1>
          <p className="mt-2 text-slate-600 dark:text-slate-400">
            Für dieses Übungsmodul ist noch kein Widget hinterlegt.
          </p>
        </div>
      );
  }
}

## Manifest-Referenz

| Feld | Pflicht | Bedeutung |
| --- | --- | --- |
| `id` | ja | Slug aus Kleinbuchstaben, Ziffern, Bindestrichen. Eindeutig. |
| `name` | ja | Anzeigename |
| `icon` | ja | Name eines lucide-Icons |
| `accent` | ja | Hex-Farbe, z. B. `#4f46e5` |
| `description` | nein | Ein Satz für die Übersicht |
| `modules` | ja | Mindestens ein Modul |

Pro Modul:

| Feld | Pflicht | Bedeutung |
| --- | --- | --- |
| `id` | ja | Slug, eindeutig innerhalb des Bereichs |
| `type` | ja | `course`, `srs-deck`, `reference`, `practice`, `library` |
| `title` | ja | Überschrift |
| `subtitle` | nein | Zusatzzeile in der Bereichsübersicht |
| `pinned` | nein | `true` setzt einen Schnellzugriff in die Kopfleiste |
| `widget` | nein | Dateiname (ohne `.tsx`) aus `widgets/` |
| `data` | nein | Pfade relativ zum Bereichsordner, `*` erlaubt |
| `dailyNewLimit` | nein | Überschreibt das globale Limit |
| `dailyReviewLimit` | nein | Überschreibt das globale Limit |

## Modultypen

- **`srs-deck`** — Karten aus `decks/*.json` im Format `{ "deck": string, "cards": Card[] }`.
  Eine Karte: `{ key, front, back, reading?, note?, example?, tags? }`. **`key` muss stabil sein** —
  er ist die Identität der Karte. Wer ihn ändert, erzeugt eine neue Karte und verliert den Fortschritt.
- **`course`** — Lektionen aus `lessons/*.mdx`. Jede Datei exportiert
  `export const meta = { id, title, order, requires }`. `requires` nennt die `id` einer Lektion,
  die vorher abgeschlossen sein muss, oder `null`.
- **`reference`** — Nachschlagen. Standardmäßig als Tabelle aus einem JSON-Array von Objekten.
- **`practice`** — freies Üben. Braucht in aller Regel ein eigenes Widget.
- **`library`** — Sammlung, die der Nutzer selbst füllt.

## MDX-Bausteine für Lektionen

`<Ziel>`, `<Handhaltung>`, `<Fehlerbild>`, `<Uebung bpm={80}>`, `<Merksatz>`, `<Hinweis>`, `<Checkpoint>`.
`<Checkpoint>` schließt die Lektion beim Klick ab.

## Eigenes Widget

Lege `skills/<id>/widgets/MeinWidget.tsx` an und trage `"widget": "MeinWidget"` im Modul ein.

```tsx
import type { WidgetProps } from "../../../packages/web/src/skills/widgets.js";

export default function MeinWidget({ data, progress }: WidgetProps) {
  return (
    <div>
      <h1 className="text-2xl font-semibold">Mein Widget</h1>
      <p>{data.length} Einträge geladen.</p>
      <button onClick={() => progress.record("uebung-1", "correct")}>Geschafft</button>
    </div>
  );
}
```

Ein Widget spricht **nie** direkt mit der Datenbank. Es bekommt `data`, `progress` und `settings` —
mehr braucht es nicht, und mehr darf es nicht nutzen.

## Fortschritt und Inhaltsänderungen

Der Seed-Abgleich läuft bei jedem App-Start. Karten hinzufügen ist gefahrlos. Karten entfernen
archiviert sie, löscht sie aber nicht — kommen sie zurück, kommt der alte Lernstand mit.
```
