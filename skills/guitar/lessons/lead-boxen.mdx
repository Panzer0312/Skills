Von tief nach hoch spielst du die Boxen in der Reihenfolge 5, 1, 2, 3, 4. Hier siehst du, wo in jeder Box
der Grundton A liegt:

- Box 5: tiefe E-Saite Bund 5, G-Saite Bund 2, hohe E-Saite Bund 5
- Box 1: tiefe E-Saite Bund 5, D-Saite Bund 7, hohe E-Saite Bund 5
- Box 2: D-Saite Bund 7, H-Saite Bund 10
- Box 3: A-Saite Bund 12, H-Saite Bund 10
- Box 4: A-Saite Bund 12, G-Saite Bund 14

**Verbinden.** Benachbarte Boxen teilen Töne. Auf jeder Saite ist der obere Ton einer Box der untere Ton
der nächsten. Box 1 und Box 2 teilen zum Beispiel Bund 7 auf der G-Saite und Bund 8 auf den zwei hohen
Saiten. Dort wechselst du die Box, ohne zu springen.

<Handhaltung>
Eine Box, eine Handposition. Beim Wechsel wandert die Hand als Ganzes und bleibt auf dem gemeinsamen Ton
kurz stehen, dann folgt der nächste Finger. Box 3 und 4 verlangen auf einzelnen Saiten eine Spreizung vom
Zeigefinger zum kleinen Finger. Die Hand lockert sich dazwischen.
</Handhaltung>

<Fehlerbild>
Jede Box klingt einzeln gut, aber im Wechsel stolperst du, weil du den gemeinsamen Ton nicht kennst und
im falschen Bund landest. Oder du schaust bei jedem Wechsel auf den Hals. Prüfe: Weißt du für Box 1 nach
Box 2 und für Box 2 nach Box 3, auf welchem Ton du wechselst?
</Fehlerbild>

<Merksatz>Die Boxen sind eine Treppe, und die gemeinsamen Töne sind die Stufen.</Merksatz>

<Uebung bpm={70}>
Metronom auf 70, ein Ton pro Achtel.

**Einzeln.** Spiele jede Box zweimal auf und ab, in der Reihenfolge 5, 1, 2, 3, 4. Sage vor dem Start,
welcher Finger auf welchem Bund beginnt.

**Verbinden.** Spiele die Tabulatur von Box 1 nach Box 2. Dann suche selbst den Wechsel von Box 2 nach Box 3
und von Box 3 nach Box 4.

**H-Saite.** Spiele die H-Saite von Bund 3 bis Bund 15 und zurück.

Steigere das Tempo in 5er-Schritten. Gemeistert ist die Lektion bei 90 BPM.
</Uebung>

<Checkpoint>Du spielst bei 70 BPM jede Box auf und ab und wechselst auf der H-Saite durch alle fünf Boxen, ohne auf die Hand zu schauen.</Checkpoint>
